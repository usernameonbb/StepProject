# IT Step სტუდენტების ქულების მართვის სისტემა

## აღწერა
საკონსოლომდებარე Python აპლიკაცია სტუდენტების აკადემიური მოსწრების მონიტორინგისთვის. პროექტი აგებულია ობიექტზე ორიენტირებული პროგრამირების (OOP) პრინციპების დაცვით და ინახავს მონაცემებს მუდმივად.

## ფუნქციონალი და არქიტექტურა
- **ობიექტზე ორიენტირებული პროგრამირება (OOP):** გამოყენებულია `StudentRegistry` კლასი მონაცემთა მართვის ლოგიკის იზოლაციისთვის.
- **მონაცემთა შენახვა:** მონაცემების მუდმივი შენახვა ლოკალურ JSON ფაილში.
- **შეცდომების დამუშავება (Exception Handling):** `try-except` ბლოკების გამოყენება არავალიდური ციფრული მონაცემების შეყვანისას პროგრამის კრაშის თავიდან ასაცილებლად.

## ტექნოლოგიები
- Python 3.x
- JSON (ჩაშენებული ბიბლიოთეკა)

## ინსტალაცია და გაშვება
1. მოახდინეთ პროექტის კლონირება GitHub რეპოზიტორიიდან.
2. გახსენით ტერმინალი პროექტის საქაღალდეში.
3. გაუშვით პროგრამა შემდეგი ბრძანებით:
   ```bash
   python main.py
   ```
